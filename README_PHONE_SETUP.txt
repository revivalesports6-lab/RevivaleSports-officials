REVIVALESPORTS — PHONE SETUP

1. Download/extract this ZIP on your Android phone.
2. Open the folder in a code editor such as Acode.
3. Open index.html and preview it in your browser.
4. Your supplied RevivaleSports logo is already in assets/logo.png.
5. To change social links, open index.html and replace the three example links near the "Ready to rise?" section.
6. To change team names/events, edit the text in index.html.
7. Do not rename assets/logo.png unless you also update its path in index.html.

PUBLISHING:
- Create a GitHub account.
- Create a new public repository.
- Upload index.html, style.css, script.js and the assets folder.
- In repository Settings > Pages, enable deployment from the main branch/root.
- GitHub will provide the public website address.

IMPORTANT:
You never need to give anyone your GitHub password. I can help you through each screen while you publish it.
